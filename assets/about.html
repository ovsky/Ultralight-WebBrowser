Features

  • Tabbed browsing with drag reordering
  • Per-tab find, zoom, and reload
  • Session restore and closed-tab recovery
  • History, bookmarks, and downloads pages
  • Search across each of those lists
  • Encrypted password manager
  • Theme manager with import and export
  • Built-in ad blocker
  • Extension manager
  • Per-site DRM playback via WebView2
  • Reader-friendly internal pages
  • Reduced-motion and high-contrast modes
  • Find in page across every tab
  • Keyboard shortcut customization set
